## [0.1.1] - 2026-09-02

### Added

- GitHub repository, issue tracker and homepage metadata for every npm package.
- Token-free npm Trusted Publishing workflow with release-tag validation and safe retry behavior.

## [0.1.0] - 2026-09-02

### Added

- Deterministic core inspection pipeline and explainable policy decisions.
- Russian and English language packs.
- Conservative transliteration, leetspeak, repeated-character and joined-token candidates.
- Unicode, repetition, caps, punctuation, contact-density, keyboard-smash and basic gibberish rules.
- npm workspace build, tests, coverage, benchmarks and package verification.
- MIT License for the workspace and all published packages.

### Compatibility

- Node.js 20 and newer.
- ESM package exports.
