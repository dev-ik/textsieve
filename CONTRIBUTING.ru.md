# Участие в разработке TextSieve

[English](CONTRIBUTING.md) | Русский

TextSieve — OSS-проект под лицензией MIT. Изменения должны сохранять детерминированность, локальное выполнение проверок и консервативное отношение к ложным срабатываниям.

## Разработка

Используйте Node.js 24 LTS и npm:

```bash
nvm use
npm install
npm run release:check
npm run benchmark
```

Минимальная поддерживаемая среда выполнения — Node.js 20. Не добавляйте runtime-зависимости, сетевые запросы, телеметрию или недетерминированное поведение.

## Правила и языковые данные

Для каждого нового детектора или элемента словаря необходимы:

- положительный пример;
- отрицательный пример;
- пограничный пример;
- реалистичный пример возможного ложного срабатывания;
- пример обфускации или Unicode, если он применим.

Не копируйте внешние словари и корпуса без совместимой лицензии и описания происхождения в [`docs/DATA_PROVENANCE.ru.md`](docs/DATA_PROVENANCE.ru.md). Предпочитайте небольшие проверенные изменения широким основам слов, глобальному нечёткому поиску и разрушающей транслитерации.

## Pull request

Делайте изменения сфокусированными и описывайте поведение, риск ложных срабатываний и выполненные проверки. Перед запросом ревью запустите `npm run release:check`.
