# ADR 0002 — Правила

[English](0002-rule-interface.md) | Русский

Статус: предложено

Правила — детерминированные инспекторы без побочных эффектов, работающие с неизменяемым `RuleContext`.

Каждое правило возвращает нормализованный сигнал от 0 до 1 и объяснимые записи `Issue`.

Правила не определяют поведение UI напрямую. Политика преобразует сигналы и проблемы в `allow`, `review` или `reject`.
