# ADR 0009 — Поддержка сред выполнения и формат модулей

[English](0009-runtime-and-module-format.md) | Русский

Статус: принято

## Контекст

TextSieve предназначен для браузеров, Node.js, Bun и edge-сред. Одновременная поддержка ESM и CommonJS потребовала бы второй сборки, условных exports и создала бы риск несовместимости dual package.

Node.js 20 больше не поддерживается разработчиками платформы, но потребителям TextSieve необходима совместимость начиная с Node.js 20.

## Решение

Пакеты ветки 0.1.x используют только ESM и объявляют `node >=20`. Runtime-код не должен импортировать встроенные модули Node.js. CI проверяет Node.js 20.10, последнюю версию линии Node.js 20, Node.js 22 и Node.js 24. Сборка для браузера является обязательной проверкой релиза.

Совместимость с Node.js 20 поддерживается на протяжении ветки 0.1.x, однако для production документация рекомендует актуальную поддерживаемую LTS-версию.

## Последствия

- Один ESM-артефакт работает на современных серверах, в bundler и edge-средах.
- Потребители CommonJS должны перейти на `import` или остаются без поддержки в 0.1.x.
- Дефекты Node.js 20 блокируют релиз, хотя upstream больше не выпускает для неё исправления безопасности.
- В будущем можно добавить dual build через условные exports без изменения TypeScript API.
