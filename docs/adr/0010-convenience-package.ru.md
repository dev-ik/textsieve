# ADR 0010 — Единый пакет для установки

[English](0010-convenience-package.md) | Русский

## Контекст

Ранее для использования обоих языковых пакетов требовалось установить и импортировать три scoped-пакета. Явная композиция удобна для минимальных сборок, но усложняет стандартную RU/EN-настройку.

## Решение

Публиковать пакет `textsieve` без scope с точными зависимостями на совпадающие версии `@textsieve/core`, `@textsieve/en` и `@textsieve/ru`. Он не содержит собственной реализации движка или языковых данных, а только переэкспортирует публичный API и типы core вместе с обоими языковыми пакетами.

Scoped-пакеты остаются основными и могут устанавливаться независимо. Версия единого пакета совпадает с версиями всех пакетов workspace; минимальная версия Node.js — 20.

## Последствия

- Стандартная установка сокращается до `npm install textsieve` и одного импорта.
- Пользователи по-прежнему могут устанавливать только нужные scoped-пакеты.
- Точные версии зависимостей делают состав единого пакета воспроизводимым.
- Релиз считается полным, только когда все четыре пакета опубликованы с одной версией.
- Первый выпуск `textsieve` необходимо выполнить вручную, прежде чем для него можно будет настроить npm Trusted Publishing.
