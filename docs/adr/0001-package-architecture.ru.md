# ADR 0001 — Архитектура пакетов

[English](0001-package-architecture.md) | Русский

Статус: принято

Использовать npm workspaces с независимым от среды выполнения ядром и отдельными языковыми пакетами.

- `@textsieve/core`: движок, типы, интерфейсы нормализации, общие правила и политика.
- `@textsieve/ru`: русский словарь безопасности, метаданные транслитерации и языковая статистика RU.
- `@textsieve/en`: английский словарь безопасности и языковая статистика EN.
- `textsieve`: удобный переэкспорт core и обоих языковых пакетов.

Ядро не должно импортировать языковые пакеты. Это сохраняет tree shaking и не позволяет включать в bundle неиспользуемые словари.

Языковые пакеты явно передаются в `createSieve()`. В workspace используется только npm; корневой `package-lock.json` фиксируется в репозитории для воспроизводимой разработки и установки в CI.
