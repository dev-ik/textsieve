# ADR 0007 — Явная композиция языковых пакетов

[English](0007-language-pack-composition.md) | Русский

Статус: принято

## Контекст

Основной пакет не должен импортировать конкретные языковые пакеты, хотя конфигурация проверки ссылается на языки по locale.

## Решение

`createSieve()` получает неизменяемые объекты языковых пакетов через `languagePacks`. Для `expectedLanguage` и каждого элемента `safetyLanguages` должен быть зарегистрирован соответствующий пакет, если требуется языковое поведение.

```ts
createSieve({
  languagePacks: [ru, en],
  expectedLanguage: "ru",
  safetyLanguages: ["ru", "en"]
});
```

Языковые пакеты могут импортировать типы ядра, но ядро никогда не импортирует языковые пакеты. Регистрация действует только внутри экземпляра и не создаёт глобальных побочных эффектов.

## Последствия

- В bundle потребителя попадают только импортированные им пакеты.
- Конфигурация детерминирована и изолирована для каждого экземпляра sieve.
- Публичный вызов немного многословнее, чем неявная глобальная регистрация.
