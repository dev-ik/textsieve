# ADR 0005 — Многопаттерновый поиск в данных безопасности

[English](0005-multi-pattern-matching.md) | Русский

Статус: предложено

Для больших статических словарей ненормативной лексики и оскорблений следует использовать скомпилированный многопаттерновый поиск.

Основной кандидат: Ахо — Корасик.

Причины:

- детерминированность;
- эффективный поиск множества шаблонов в одной строке;
- отсутствие N полных проходов по строке;
- пригодность для синхронной фильтрации форм и чатов.

Перед окончательным выбором сравните производительность с более простой реализацией. Оставьте matcher внутренней деталью, чтобы реализацию можно было заменить без нарушения публичного API.

Метаданные шаблона должны сохранять каноническое слово, locale, правило или серьёзность и сведения об исключениях.
