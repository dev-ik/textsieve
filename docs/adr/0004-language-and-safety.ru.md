# ADR 0004 — Ожидаемый язык и язык безопасности

[English](0004-language-and-safety.md) | Русский

Статус: принятое архитектурное ограничение

`expectedLanguage` и `safetyLanguages` независимы.

Русскоязычное поле может принимать английские технические термины и при этом обнаруживать английскую ненормативную лексику.

Транслитерация создаёт кандидаты для каждого токена и никогда не перезаписывает исходный или нормализованный текст.

Так обычный многоязычный технический текст не признаётся недопустимым, а межъязыковые оскорбления продолжают обнаруживаться.
