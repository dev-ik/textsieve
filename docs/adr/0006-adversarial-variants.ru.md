# ADR 0006 — Варианты враждебного текста

[English](0006-adversarial-variants.md) | Русский

Статус: предложено

Пользователи обходят фильтры слов с помощью:

- опечаток;
- замены символов цифрами и специальными знаками;
- пробелов между буквами;
- повторяющихся букв;
- склеенных слов;
- транслитерации.

TextSieve обрабатывает только детерминированные консервативные варианты.

Конвейер:

```text
исходный токен -> нормализованный токен -> деобфусцированные кандидаты -> кандидаты транслитерации -> matcher
```

Не используйте неограниченное нечёткое расстояние редактирования. Защита от ложных срабатываний — требование первого уровня.
