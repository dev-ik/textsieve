# ADR 0003 — Оценка

[English](0003-scoring-model.md) | Русский

Статус: предложено

Каждый сигнал находится в диапазоне от 0 до 1. Итоговая оценка качества — от 0 до 100, где 100 означает чистый текст высокого качества.

Не калибруйте веса только интуитивно. Сначала создайте fixtures, зафиксируйте ожидаемые диапазоны, затем настройте детерминированные веса и пороги.

Одно точное совпадение с высоким уровнем серьёзности может привести к отклонению политикой без низкой итоговой оценки качества.
