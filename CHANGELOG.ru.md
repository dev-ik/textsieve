# История изменений

[English](CHANGELOG.md) | Русский

В этом файле документируются все заметные изменения TextSieve.

## [Не выпущено]

## [0.1.1] — 2026-09-02

### Добавлено

- Пакет `textsieve` без scope для установки одной командой и импорта из единой точки входа.
- Metadata GitHub-репозитория, issue tracker и homepage для каждого npm-пакета.
- Workflow npm Trusted Publishing без постоянного токена, с проверкой release-тега и безопасным повторным запуском.
- Абсолютные ссылки переключения языка во всех README пакетов, совместимые с отображением на npm.

## [0.1.0] — 2026-09-02

### Добавлено

- Детерминированный основной конвейер проверки и объяснимые решения политики.
- Русский и английский языковые пакеты.
- Консервативные кандидаты на основе транслитерации, литспика, повторяющихся символов и склеенных токенов.
- Правила для Unicode, повторов, верхнего регистра, пунктуации, плотности контактных данных, клавиатурных последовательностей и базового бессмысленного текста.
- npm workspace, сборка, тесты, покрытие, бенчмарки и проверка пакетов.
- MIT License для workspace и всех публикуемых пакетов.

### Совместимость

- Node.js 20 и новее.
- Экспорт пакетов в формате ESM.
